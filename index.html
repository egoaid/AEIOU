AEIOU Vocal Synthesizer — 取扱説明書
Christmas Edition v1.2 ／ Pink Trombone LF声道モデルによる物理モデリング歌声シンセサイザー
AEIOUは、Neil Thapen氏の Pink Trombone(声帯振動と声道共鳴を物理的にシミュレートするエンジン)を核に、 MIDIファイル再生・最大4声のポリフォニー・SATB自動振り分け・雪だるまキャラクターアニメーションなどを組み合わせた、 クリスマスパーティー向けの「歌う雪だるま」演奏アプリです。キーボード演奏はもちろん、MIDIファイルを読み込ませて 無人でクリスマスの讃美歌を歌わせ続けることもできます。
1. はじめに使うには
画面右下の ▶ START ボタン、またはPCキーボード/画面上の鍵盤/MIDIキーボードのいずれかを 最初に操作すると音声エンジンが起動します(ブラウザの自動再生制限のため、必ず何らかの操作が必要です)。 起動後はエンジン状態ドット(ヘッダー左上)が点灯し、雪だるまが画面上部の劇場で待機します。
2. 演奏方法
  • PCキーボード: A W S E D F T G Y H U J K が鍵盤(白鍵/黒鍵)に対応。 Z / X でオクターブを上下できます(現在のオクターブは鍵盤セクションに表示)。
  • マウス/タッチ: 画面下部のピアノ鍵盤をクリック/タップ、またはドラッグして複数の鍵を弾けます。
  • MIDIキーボード: ブラウザのMIDIアクセス許可後、自動的に接続されます(ヘッダーの「MIDI ✓」表示で確認可)。 Note On/Off、ベロシティ、モジュレーションホイール(CC1)、ピッチベンド、オールノートオフ(CC123)に対応しています。
  • PANIC: 発音中の音をすべて即座に停止します。音が止まらなくなった場合に使用してください。
  • ⏺ REC: エンジン出力をそのまま録音し、停止するとWAVファイルとして自動ダウンロードされます。
3. VOWEL / TONGUE POSITION(母音・舌の位置)
A・E・I・O・U ボタンで基本母音を選ぶか、下のXYパッド上を直接クリック/ドラッグして母音間を連続的に変化させられます。 パッドの横軸は舌の前後位置(左=後舌/BACK、右=前舌/FRONT)、縦軸は開口の狭さ(上=狭い/CLOSE、下=広い/OPEN)を表す、 音声学の「母音四辺形」に基づいた配置です。演奏中にドラッグすると、なめらかに母音が移り変わります。
4. LEGATO(レガート)
LEGATO ON/OFF で有効・無効を切り替えられます。THRESHOLD は、 前の音が鳴り終わってからこの時間(ms)以内に次の音を弾いた場合に「つながっている」とみなす猶予時間です。 BLEND は音程が次の音へ移行する速さで、値が低いほどなめらかに、高いほど素早く音程が切り替わります。
5. HARMONY(ハーモニー)/ ボイスキャラクター
  • SOLO: 1音だけを演奏する通常モード。空いている物理Voiceのうち最も余韻が少ないものが自動選択されるため、 前の音の残響とぶつからず自然に立ち上がります。
  • POLY: 最大4音までの同時演奏(和音)が可能なモード。押した音は自動的に空いているVoice(V1〜V4)へ割り当てられ、 4音とも使用中の場合は最も古く押した音が新しい音に譲られます(ボイススティール)。
  • VOICE CHARACTER (V2/V3/V4): POLYで複数の声を同時に鳴らす際、各Voiceの声質を個別に調整できます。 SIZE(声道サイズのオフセット)・TENS(張りのオフセット)・DETUNE(音程のわずかなズレ、合唱のゆらぎ効果)の3つがあります。 年齢・性別のような大きな声質差は下記の VOICE DNA の PHARYNX が担当するため、ここは基本 0 のままにし、 明確に別の声を混ぜたい場合のみ調整することを推奨します。
  • HUMANIZE: 4つのVoiceそれぞれの微細なゆらぎに個体差を持たせるパラメータです。 PHASE(揺れの位相オフセット)、VIB FREQ(ビブラート周波数のばらつき)、VIB AMT(ビブラート深さのばらつき)で、 全Voiceが完全に同期して機械的に聞こえるのを防ぎます。
6. VOICE PARAMETERS(声のパラメータ)
  • TENS(Tenseness): 声帯の張り。0=息っぽく柔らかい ↔ 1=張って明瞭(オペラ的)。鍵盤演奏時はベロシティからも自動計算されます。
  • RELEASE: 音を離したときに声が消えるまでの速さ。速いパッセージには速め、独唱でゆったり伸ばすなら遅めが向いています。
  • VIBRATO: 意図的にかけるビブラートの深さ。
  • VIB REALISM: ビブラートの「立ち上がり」(発音直後はストレート→徐々に満ちる)と、速さ・深さの緩やかな揺らぎを制御。低いほど鍵盤楽器のように規則的、高いほど人間の歌唱らしくなります。
  • WOBBLE: 常時かかる不規則なピッチ/張りのゆらぎ量。低=安定した声、高=不安定で震えるような声。VIBRATOとは独立した軸です。
  • RAWNESS: 発音の始まりや音程が移り変わる瞬間だけに生じる「生々しさ」。低=滑らかでシンセ的、高=人間がその場で声を合わせるような質感。持続音には影響しません。
  • DYNAMICS: 持続音に自然な強弱(息の揺らぎ)を加えます。MIDIは音が鳴っている間ずっと一定音量になりがちなので、それを補って生きた持続音にします。
  • STRAIN(Register Strain): その声にとって無理のある高さ・低さの音を歌う際の負担をシミュレートします。不安定さが増え、音量上限が下がり、長く伸ばすと疲労で早くハリが落ちます。自然な音域内の声には影響しません。
  • VEL GAIN: MIDIキーボードのベロシティ(強弱)がどれだけ音量に反映されるかを調整します。100%が基準で、上げるほど中〜低ベロシティでもしっかり音量が出るようになります。
  • VOL: マスター音量。
  • VOICE SIZE: 声道の物理的な長さそのものをスケールします(50%=小さく明るい声 ↔ 150%=大きく低い声)。ピッチには影響せず、フォルマント(音色)だけが変化します。
  • AUTO BREATH: 発音の瞬間に自動で息っぽさを加える機能。DURATION(息の長さ)、DEPTH(深さ。低いほど息っぽい)、CURVE(息→声への回復カーブ)、LEGATO(レガートで音程が変わる瞬間の軽い息継ぎ量)を調整できます。
  • MOD WHL / ORDER: MIDIのモジュレーションホイール(CC1)で母音を連続的に変化させます。ORDERで、ホイールを動かしたときに通過する母音の順番(A→E→I→O→Uなど25パターン)を選べます。
  • PITCH WHL: MIDIのピッチベンドホイールを音量コントロールとして使用します(上げる=最大2倍、下げる=ミュートまで)。
7. ADT & STEREO ECHO(エフェクト)
ADT(Automatic Double Tracking)は、左右にわずかに異なる固定ディレイ(15ms/22ms)をかけて、 音色を変えずにステレオの広がりだけを作るエフェクトです。STEREO ECHO は ディレイタイム・ミックス量・フィードバック量を調整できる、教会的な残響感を加えるエコーです。それぞれON/OFFボタンで無効化できます。
8. VOICE DNA(声質の個体差)
V1〜V4それぞれの声帯そのものの「指紋」を絶対値で設定できるパネルです。 JITTER/SHIMMER は周期ごとの微小な音程・音量のゆらぎ、 BREATH は全力で張っても残る息漏れの量、TILT は声源自体の明るさ/こもり、 PHARYNX は咽頭側を優先的に伸ばす非対称な声道伸長(0%=子供・女声寄り、50〜100%=成人男声寄り)です。 VOICE AUDITION で特定のVoiceだけをソロで聴き比べることもできます(SOLOモードで有効、POLYでは対象外)。
9. MIDI FILE PLAYER(MIDIファイル再生)
  • 「ファイルを追加」から.mid/.midiファイルを1つ以上選択すると、プレイリストに追加されます。
  • 読み込み時、音域の高い順に V1(Soprano)〜V4(Bass) へ自動的にトラックが割り当てられます(ドラムトラックは除外)。手動でV1〜V4 TRACKのプルダウンから割り当てを変更することもできます。
  • 和音を含むトラックは最高音をメロディとして抽出し、各Voiceは単音(モノフォニック)で再生します。
  • 声質(VOICE SIZE等)は現在選択中のプリセットの設定がそのまま使われます — MIDIは音程のみを担当します。
  • RELEASE / LEGATO threshold / VIBRATO は曲のテンポ(BPM)から自動計算され、曲が切り替わるたびに再計算されます(再生中は手動調整不可)。速い曲ほど声の切れを良く、遅い曲ほどなめらかに繋げます。
  • プレイリストは複数曲を並べてLOOP再生できます。再生中に別の曲をクリックすると、まず現在の音を止めて0.5秒の無音を挟んでから選択した曲を再生します(前の曲の音が重なって残るのを防ぐため)。
10. EXTERNAL AUDIO SYNC(外部オーディオ同期再生)
他のシンセ/ドラムマシーンWEBアプリなどで書き出した音源ファイルを読み込み、AEIOUの演奏や録音とテンポを揃えるための機能です。 「◈ VOICE PARAMETERS」パネルの下にある「◈ EXTERNAL AUDIO SYNC」パネルから操作します。
  • ファイルを選択: mp3/wav等の音声ファイルを読み込みます。
  • ▶ PLAY / ⏸ PAUSE / ■ STOP: 標準的な音楽プレーヤーとして単独で再生・一時停止・停止ができます。AEIOUの鍵盤演奏やMIDIファイル再生と同時に鳴らすことも可能です。進捗バーと経過時間/総時間の表示で、あとどれくらい残っているか一目でわかります。
  • REC時に自動再生する: ONの状態で ⏺ REC を押すと、録音開始と全く同じタイミングで外部ファイルが(通常再生の位置に関わらず)必ず先頭から再生されます。
  • 重要: この外部ファイルの音はスピーカーには出力されますが、AEIOUの録音(WAV書き出し)には一切含まれません。書き出されたWAVを外部ファイルと同じDAWプロジェクトに読み込めば、頭出しのタイミングが揃います(=テンポが同期した状態で編集できます)。
  • VOLUME: モニター(スピーカー出力)の音量のみを調整します。録音内容には影響しません。
11. プリセット
ヘッダー下のプリセットバーから、合唱団・ソロボイス・雰囲気・キャラクターなど29種類の組み込みプリセットを呼び出せます。 LOAD で選択中のプリセットを適用、SAVE で現在の全設定に名前を付けてブラウザに保存、 RESET で最初のプリセットに戻す、DELETE で保存したユーザープリセットを削除できます。 JSON OUT / JSON IN で、保存したユーザープリセットをファイルとして書き出し・読み込みできるので、 他のブラウザ/PCへ持ち運ぶことも可能です。
🎲 RANDOMIZE ボタンを押すと、声とエフェクトに関わるほぼ全パラメーターを一度にランダム生成します — TENS/WOBBLE/RAWNESSなどの声質パラメーター、LEGATO・AUTO BREATH・CONSONANT ATTACK、HARMONY(SOLO/POLY)、 VOICE CHARACTER(V2〜V4)、HUMANIZE、ADT & STEREO ECHO、VOICE DNA(V1〜V4個体差)、オクターブ、母音まで、 「◈ EXTERNAL AUDIO SYNC」を除くほぼ全てが対象です(LF GLOTTIS RESEARCHパネルなど一部の実験的機能は、 破綻したノイズを避けるため対象外です)。各パラメーターは完全な一様乱数ではなく、実際のプリセット群に近い 実用的な範囲でランダム化されるため、「聴ける音」と「予想もしない意外な声」のバランスを取ってあります。 気に入った偶然の産物は SAVE でユーザープリセットとして保存できます。
12. 画面表示
雪だるまの劇場は発声に合わせて口の形・頬の赤み・音符アニメーションなどが変化します。右上の ⛶ ボタンで 全画面表示に切り替えられ、パーティー会場のスクリーンに映すのに向いています。
13. 言語切替 / 取扱説明書
ヘッダー右上の JP / EN ボタンでUI全体の表示言語を切り替えられます。この取扱説明書も、 モーダル右上の JP / EN ボタン(またはメインの言語切替と連動)で日本語・英語を切り替え可能です。
14. 仕様
音声エンジンPink Trombone (Neil Thapen, 2017) — LF (Liljencrants-Fant) 声帯振動モデル + 声道導波管(waveguide)モデルによる物理モデリング歌声合成。tenseness → Rd → Ra/Rk/Rg の結合式で声質を制御。
ポリフォニー最大4声(独立したGlottis+Tractのペアを4基搭載)。SOLOは1声、POLYは最大4声同時発音。MIDIファイル再生時はSATB(V1〜V4)として使用。
声道モデル可変セグメント数(16〜116、既定44)による真の声道長スケーリング。母音形状は新しい長さへ線形補間で引き継がれる。咽頭優先伸長(PHARYNX)で成人男声特有の非対称な声道形状も再現。
オーディオ処理Web Audio API ScriptProcessorNode、ブロックサイズ2048サンプル。サンプルレートはブラウザのAudioContextに準拠(通常44.1kHzまたは48kHz)。
最終段リミッターDynamicsCompressor(閾値 -3dBFS、レシオ20:1、アタック1ms、リリース100ms)でクリップ・爆音を防止。
MIDI対応Web MIDI API。Note On/Off(ベロシティ対応)、CC1(モジュレーションホイール→母音変化)、CC123(オールノートオフ)、ピッチベンド(音量コントロール、0〜200%)。
MIDIファイル標準MIDIファイル(SMF)フォーマット0/1に対応。フォーマット0はチャンネルごとに自動分割。テンポマップに基づく正確なタイミング再生。
録音MediaRecorderでエンジン最終出力(リミッター後)をキャプチャし、AudioContextでデコードして16bit PCM WAV(ピークノーマライズ付き)として書き出し。
プリセット組み込み29種 + ユーザープリセット(ブラウザのlocalStorageに保存、JSON形式でエクスポート/インポート可)。
動作環境Web Audio API対応ブラウザ(Chrome/Edge等推奨)。MIDI入出力にはWeb MIDI API対応が必要(Safari等は非対応の場合あり)。全画面表示にはFullscreen API対応が必要。

AEIOU Vocal Synthesizer — User Manual
Christmas Edition v1.2 / A physically-modeled singing voice synthesizer built on the Pink Trombone LF vocal-tract model
AEIOU is built around Neil Thapen's Pink Trombone engine — a physical simulation of the glottis and vocal tract — combined with MIDI file playback, up to 4-voice polyphony with automatic SATB voice allocation, and a singing snowman character animation. It's designed as a "singing snowman" performer for Christmas parties: play it live from a keyboard, or load a MIDI file and let it sing carols unattended.
1. Getting Started
Click ▶ START at the bottom right, or simply play a note on the PC keyboard, on-screen piano, or a connected MIDI keyboard — any of these will start the audio engine (browsers require a user interaction before audio can play). Once running, the status dot in the header lights up and the snowman waits on stage at the top of the screen.
2. Ways to Play
  • PC keyboard: A W S E D F T G Y H U J K map to white/black piano keys. Z / X shift the octave down/up (current octave shown in the keyboard section).
  • Mouse / touch: click or tap the on-screen piano; drag across keys to play several notes in sequence.
  • MIDI keyboard: connects automatically once you grant MIDI access (check the "MIDI ✓" indicator in the header). Supports Note On/Off with velocity, Modulation Wheel (CC1), Pitch Bend, and All Notes Off (CC123).
  • PANIC: instantly silences every currently sounding note — use this if a note gets stuck.
  • ⏺ REC: records the engine's output; stopping the recording automatically downloads a WAV file.
3. Vowel / Tongue Position
Use the A/E/I/O/U buttons to jump to a base vowel, or click/drag directly on the XY pad below to morph continuously between vowels. The pad is laid out like a phonetic "vowel quadrilateral": the horizontal axis is tongue front/back position (left=BACK, right=FRONT), and the vertical axis is mouth openness (top=CLOSE/narrow, bottom=OPEN/wide). Dragging while playing produces a smooth glide between vowel sounds.
4. Legato
Toggle with LEGATO ON/OFF. THRESHOLD is the grace period (ms): if you play the next note within this window after the previous one ends, the notes are treated as connected/legato. BLEND controls how quickly pitch glides to the new note — lower is smoother, higher is snappier.
5. Harmony / Voice Character
  • SOLO: the standard single-note mode. The quietest available physical Voice is automatically chosen for each new attack, so a fresh note never collides with the natural decay of the previous one.
  • POLY: up to 4 simultaneous notes (chords). Each key press is auto-assigned to a free Voice (V1–V4); if all four are busy, the oldest held note is stolen and reassigned.
  • VOICE CHARACTER (V2/V3/V4): when multiple voices sound together in POLY, each Voice's character can be nudged individually — SIZE (vocal-tract-size offset), TENS (tenseness offset), and DETUNE (a slight pitch offset for choir-like shimmer). Larger age/gender differences are better handled by PHARYNX in VOICE DNA below, so keep these at 0 unless you want to deliberately blend a distinct voice type.
  • HUMANIZE: gives each of the 4 Voices slightly different micro-fluctuations so they never sound perfectly synchronized/mechanical — PHASE (noise-phase offset), VIB FREQ (vibrato-rate variation), and VIB AMT (vibrato-depth variation).
6. Voice Parameters
  • TENS (Tenseness): vocal-fold tension. 0 = breathy/soft ↔ 1 = pressed/operatic. Also computed automatically from keyboard velocity.
  • RELEASE: how quickly a note fades after release — fast for quick passages, slow for a natural, sustained solo tail.
  • VIBRATO: depth of intentional vibrato.
  • VIB REALISM: controls the vibrato's onset ramp (straight tone at attack, filling in gradually) and its slow rate/depth drift. Low = mechanical/keyboard-like, high = natural human singing.
  • WOBBLE: a constant, irregular pitch/tension wobble. Low = stable voice, high = unsteady/tremulous. Independent of VIBRATO.
  • RAWNESS: "rawness" that appears only during attacks and pitch transitions. Low = smooth/synthetic, high = the grainy quality of a human voice finding the pitch in real time. No effect on sustained notes.
  • DYNAMICS: adds natural loudness fluctuation (breath variation) to sustained notes, compensating for MIDI's flat note-on volume so held notes feel alive.
  • STRAIN (Register Strain): simulates the vocal effort of singing outside this voice's comfortable range — more instability, a lower volume ceiling, and faster fatigue on long held notes. No effect within the comfortable range.
  • VEL GAIN: how strongly MIDI keyboard velocity translates into volume. 100% is neutral; raising it makes moderate/low-velocity playing sound noticeably louder.
  • VOL: master output volume.
  • VOICE SIZE: scales the physical length of the vocal tract itself (50% = small/bright voice ↔ 150% = large/dark voice). Pitch is unaffected — only the formants (timbre) change.
  • AUTO BREATH: automatically adds a breathy onset to each attack. DURATION (length of the breath), DEPTH (how breathy — lower is breathier), CURVE (recovery curve from breath to full voice), and LEGATO (a light breath on legato pitch changes, scaled by interval size).
  • MOD WHL / ORDER: the MIDI mod wheel (CC1) morphs continuously through vowels. ORDER selects which sequence of vowels (one of 25 orderings, e.g. A→E→I→O→U) the wheel sweeps through.
  • PITCH WHL: repurposes the MIDI pitch-bend wheel as a volume control (up to 2× volume, down to mute).
7. ADT & Stereo Echo (Effects)
ADT (Automatic Double Tracking) applies slightly different fixed delays to the left and right channels (15ms / 22ms) to widen the stereo image without changing the timbre. STEREO ECHO adds a church-like ambience with adjustable delay time, mix, and feedback. Both effects can be toggled on/off independently.
8. Voice DNA (Individual Voice Character)
A panel for setting each Voice's (V1–V4) own vocal-fold "fingerprint" as absolute values. JITTER/SHIMMER are cycle-to-cycle pitch/amplitude micro-variation, BREATH is the residual breathiness that remains even at full tension, TILT is the source's inherent brightness/darkness, and PHARYNX elongates the pharynx side of the tract asymmetrically (0% = child/female-leaning, 50–100% = adult-male-leaning). Use VOICE AUDITION to solo an individual Voice for direct A/B comparison (works in SOLO mode; not applicable to POLY).
9. MIDI File Player
  • Click "Add File" and select one or more .mid/.midi files to add them to the playlist.
  • On load, tracks are auto-assigned to V1 (Soprano) – V4 (Bass) by pitch range, highest first (drum tracks are excluded). You can also reassign tracks manually from the V1–V4 TRACK dropdowns.
  • Chords are reduced to the highest note as the melody; each Voice plays monophonically.
  • Voice character (VOICE SIZE, etc.) uses whatever the currently loaded preset specifies — the MIDI file only supplies pitch/timing.
  • RELEASE / LEGATO threshold / VIBRATO are auto-calculated from the song's tempo (BPM) and recomputed whenever the song changes (locked to manual adjustment during playback). Faster songs get crisper note releases; slower songs connect more smoothly.
  • The playlist can queue multiple songs with looping. Clicking a different song while one is playing stops the current audio and waits 0.5 seconds of silence before starting the newly selected song, so the previous song's tail never overlaps the next one.
10. External Audio Sync
Loads an audio file exported from another synth/drum-machine web app and keeps it aligned in tempo with your AEIOU performance or recording. Controlled from the "◈ EXTERNAL AUDIO SYNC" panel, located below the "◈ VOICE PARAMETERS" panel.
  • Choose File: loads an mp3/wav/etc. audio file.
  • ▶ PLAY / ⏸ PAUSE / ■ STOP: a standard music-player transport — play, pause, and stop the file on its own. It can also play at the same time as AEIOU's keyboard performance or MIDI file playback. A progress bar plus elapsed/total time display shows at a glance how much is left.
  • Auto-play on REC: when enabled, pressing ⏺ REC always starts the external file from the beginning (regardless of its current playback position) at the exact same moment recording starts.
  • Important: this external audio is heard through your speakers but is never included in AEIOU's recording (WAV export). Import the exported WAV into the same DAW project as the external file and the start points will line up (i.e. you can edit with tempo already synced).
  • VOLUME: adjusts monitor (speaker) volume only — it has no effect on the recording.
11. Presets
The preset bar below the header offers 29 built-in presets spanning choirs, solo voices, atmospheric textures, and character voices. LOAD applies the selected preset, SAVE stores all current settings under a name in your browser, RESET restores the first built-in preset, and DELETE removes a saved user preset. JSON OUT / JSON IN let you export/import your saved user presets as a file, so you can carry them to another browser or computer.
The 🎲 RANDOMIZE button generates new random values for almost every parameter that shapes the voice and effects at once — voice-quality parameters like TENS/WOBBLE/RAWNESS, LEGATO, AUTO BREATH, CONSONANT ATTACK, HARMONY (SOLO/POLY), VOICE CHARACTER (V2–V4), HUMANIZE, ADT & STEREO ECHO, VOICE DNA (V1–V4 individual differences), octave, and the current vowel are all included (aside from EXTERNAL AUDIO SYNC). A few experimental features, such as the LF GLOTTIS RESEARCH panel, are intentionally left untouched to avoid producing broken, unusable noise. Each parameter is randomized within a practical range close to what's actually used across the built-in presets — not a fully uniform random draw — striking a balance between "still listenable" and "genuinely unexpected." If you land on a happy accident, use SAVE to keep it as a user preset.
12. Display
The snowman's stage animates its mouth shape, cheek blush, and floating musical notes in sync with the voice. The ⛶ button at the top right toggles fullscreen — handy for projecting onto a party screen.
13. Language Switch / This Manual
The JP / EN buttons in the header switch the entire UI's display language. This manual can likewise be switched between Japanese and English using the JP / EN buttons at the top of this window (kept in sync with the main language toggle).
14. Specifications
Voice enginePink Trombone (Neil Thapen, 2017) — physically-modeled singing voice synthesis combining an LF (Liljencrants-Fant) glottal source model with a waveguide vocal-tract model. Voice quality is driven by the tenseness → Rd → Ra/Rk/Rg coupling.
PolyphonyUp to 4 voices (four independent Glottis+Tract engine pairs). SOLO uses 1 voice; POLY sounds up to 4 at once. Used as SATB (V1–V4) during MIDI file playback.
Vocal tract modelTrue vocal-tract-length scaling via a variable segment count (16–116, default 44). Vowel shapes are resampled to the new length via linear interpolation. Pharynx-priority elongation (PHARYNX) reproduces the asymmetric tract shape typical of adult male voices.
Audio processingWeb Audio API ScriptProcessorNode, 2048-sample block size. Sample rate follows the browser's AudioContext (typically 44.1kHz or 48kHz).
Output limiterDynamicsCompressor (threshold -3dBFS, ratio 20:1, attack 1ms, release 100ms) as a final safeguard against clipping.
MIDI supportWeb MIDI API. Note On/Off with velocity, CC1 (mod wheel → vowel morph), CC123 (All Notes Off), and Pitch Bend (volume control, 0–200%).
MIDI filesStandard MIDI File (SMF) format 0/1. Format 0 files are automatically split per channel. Playback timing follows the file's tempo map precisely.
RecordingMediaRecorder captures the engine's final (post-limiter) output, which is decoded via AudioContext and re-encoded as 16-bit PCM WAV with peak normalization.
Presets29 built-in presets, plus user presets saved to browser localStorage (exportable/importable as JSON).
RequirementsA browser with Web Audio API support (Chrome/Edge etc. recommended). MIDI I/O requires Web MIDI API support (not available in some browsers, e.g. Safari). Fullscreen display requires Fullscreen API support.
